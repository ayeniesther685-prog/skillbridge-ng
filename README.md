# SkillBridge NG
  Skills, Jobs and Freelance Marketplace

SkillBridge NG is a Spring Boot backend application designed to connect skilled individuals with clients, businesses, and organizations looking for talent.

The platform aims to make it easier for students, freelancers, and professionals to discover opportunities while helping businesses find suitable skilled workers.

 Project Goals

* Connect skilled individuals with job and freelance opportunities
* Allow clients and businesses to find suitable talent
* Provide user profiles and skill information
* Support different user roles
* Provide a foundation for future AI-powered career and job-matching features
* Create a platform that can eventually support monetization through premium services and marketplace transactions
